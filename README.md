### 📦 Featured Architectural Case Studies

#### 1. 🏥 Asas Enterprise Suite (Polyglot Monorepo)
> **Healthcare ERP, Biometrics, Vault Management & Remittance System**
* **Polyglot Core**: Powered by **Rust (Tauri v2)** for AES-256-GCM hardware-locking & Tokio UDP zero-config network discovery.
* **Low-Latency Backend**: **Fastify / Bun** engine with Drizzle ORM supporting dynamic SQLite and PostgreSQL connection pools.
* **Hardware Integration**: Custom ESC/POS thermal printing engine with Arabic glyph shaping & ADMS biometric push protocols.

#### 2. 🏖️ Zwara (زوارة) Hospitality & Escrow Platform
> **Full-Stack Vacation Rental Marketplace & Double-Entry Financial Ledger**
* **Architecture**: React 19 SPA + Fastify 5.8 backend orchestrated via **Turborepo & Bun**.
* **Financial Integrity**: Double-entry wallet ledger with atomic MySQL transactions to prevent double-booking.
* **Real-Time Event Engine**: Bi-directional polymorphic WebSocket bus (`WsEventFactory`) paired with Firebase Push Notifications.
